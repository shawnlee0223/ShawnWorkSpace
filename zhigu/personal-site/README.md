# Shawn Lee 个人网站

与知股共用现有 Node 服务，仍部署于用户指定的火山引擎 ECS。未创建其他托管站点。

## 页面

- `/`：个人首页
- `/about`：关于我
- `/resume`：简历，支持浏览器打印或另存为 PDF
- `/projects`：按要求留空
- `/thoughts`：三篇待审阅的整理草稿
- `/zhigu`：原知股应用，API 继续要求管理员登录

编辑 `personal-site/build.mjs`，执行 `npm run build:personal` 生成 `public/personal/*.html`。样式、图标及打印交互在 `public/personal/`。页面采用固定路由白名单，不提供任意目录访问。
